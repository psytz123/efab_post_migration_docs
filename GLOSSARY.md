# Glossary
- **Task API:** Vendor‑neutral verb interface for robots/AMRs.
- **Manufacturing Graph:** Data model of cells, ops, routings, yields, energy.
- **Edge Agent:** Site‑local executor and adapter host with offline resilience.
- **Open‑RMF:** Open Robotics Middleware Framework for site‑wide coordination.
- **OPA/OPAL:** Policy engine & live policy distribution.
- **OTel:** OpenTelemetry for traces/metrics/logs.
